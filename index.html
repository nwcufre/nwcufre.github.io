Project 4: HR Management Dashboard on Excel

Excel-only dashboard using a collection of monthly .CSV files from an HR agency. The data was consolidated on Power Query and modeled in Power Pivot, where I built DAX measures and Pivot Tables to generate key metrics and visualizations. The solution was designed to be automated: adding fresh data to the data folder would update all charts and KPIs. The dashboard provides insights into workforce composition and trends like headcount, pay type, full and part-time status, gender, ethnicity, and termination patterns over time.

  • Power Query
  • Power Pivot
  • Excel
  • Pivot Tables
  • DAX
